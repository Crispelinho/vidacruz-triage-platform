## 1. Status vocabulary — four separate values, never conflated

| Literal value | Meaning used in this document |
| --- | --- |
| `structurally verifiable` | The check names artifacts and a pass/fail condition; it can be evaluated **if** the inputs exist. It does not mean the inputs exist. |
| `definition pending` | A predicate, hook, mechanism, numeric value or policy is still undefined; evaluation is not possible yet. |
| `evidence pending execution` | The supporting artifact is listed but has not been produced, run or observed. |
| `satisfied = no` | The finding is not closed. This is true for all 18 findings below. |

The first three states are cumulative in practice but **not interchangeable**: a structurally verifiable check can remain blocked by a definition and by unexecuted evidence at the same time.
